# ⌚ SmartFit Pro Smartwatch Product Landing Page

A flagship, responsive, and ultra-modern product landing page for the **SmartFit Pro Smartwatch**, engineered with HTML5, CSS3, and JavaScript.

Developed by **SmartFit Pro Team**  
Department of CSE (Artificial Intelligence & Machine Learning)  
Ramachandra College of Engineering, Eluru, Andhra Pradesh  

---

## 🌟 Highlights & What's New

Compared to standard templates, this project features:
- **Obsidian Glassmorphic Dark Theme**: Deep midnight palette (`#07090e`) with electric cyan (`#00f2fe`) and neon sapphire accents (`#4facfe`).
- **High-Definition Smartwatch Photography**: Completely updated, professional smartwatch visuals for every section (Hero, About, Sports, Front Dial, Side Profile, Notifications, Charging Dock).
- **Interactive Lightbox Modal**: Click any photo in the Product Gallery to inspect it in full high-resolution with captions.
- **Interactive Order Modal ("Buy Now")**: Color swatch switcher (Titanium Black, Cyber Silver, Rose Gold) and simulated Cash-on-Delivery checkout flow.
- **Biometric Telemetry Simulation**: Live animated pulse rate fluctuation (BPM) on the hero badge.
- **Interactive Contact Form**: Real-time JavaScript validation for Name, Email, Phone, and Message with animated success notifications.
- **Fully Responsive**: Seamless layout on mobile, tablet, laptop, and ultra-wide displays.

## 🚀 How to Run Locally

1. Clone or download this project folder.
2. Double-click `index.html` to open it in any web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
3. No server or complex build tools needed — purely vanilla HTML5, CSS3, and JavaScript!

## 🌐 Free Deployment to Vercel

1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com) and import the repository.
